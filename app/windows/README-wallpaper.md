# Agent Office on the desktop (Windows runner)

## Build and run
- `flutter run -d windows` from `app/` (or `flutter build windows` and run `build/windows/x64/runner/Release/agent_office_app.exe`). No flags = wallpaper mode: a borderless, full-screen window parked behind the desktop icons that paints a copy of the desktop wallpaper as its backdrop. `--window` shows the same stage in a plain dark window (no WorkerW trick, handy for testing); `--fake` replays canned vendor output instead of launching `claude`/`codex`.
- Compiled and checked on Windows 10 22H2 (MSVC, Flutter 3.41.2). The Win32 code lives in `runner/desktop_layer.cpp` (WorkerW, cursor watch, window region) and `runner/desktop_wallpaper.cpp` (IDesktopWallpaper); the channel is the `MethodChannel` lambda in `runner/flutter_window.cpp`.

## How it works
- WorkerW trick (`runner/desktop_layer.cpp`): `FindWindow("Progman")` gets `0x052C`, which makes the shell spawn a WorkerW behind `SHELLDLL_DefView` (on 24H2 a child of Progman, earlier the sibling right after it); the window is `SetParent`ed under it, so the icons draw over it.
- No transparency down there. A child of WorkerW is composed opaque: DWM per-pixel alpha does not apply, and a layered colour key (`WS_EX_LAYERED` + `LWA_COLORKEY`) swallows Flutter's DirectX output altogether (the window shows nothing at all; verified on 22H2). So the runner reads the primary monitor's wallpaper through `IDesktopWallpaper` (file, placement, background colour, monitor and virtual-screen rects; channel call `wallpaper`) and Dart paints a copy of it under the office (`lib/desktop/wallpaper.dart`, `WorldPainter._paintWallpaper`). `main` loads it before the first frame so nothing flashes; the stage re-reads it every 5 s (a window behind the icons gets no `WM_SETTINGCHANGE` broadcast), so slideshows and a new picture follow.
- A window down there gets no mouse input, so a 40 ms timer polls the cursor: inside a hit rect Dart reported (stations, characters, an open bubble) and with only the desktop under the cursor, the window is raised to a topmost top-level window; it goes back when the cursor leaves unless Dart pinned it (`bringToFront`, bubble open). While raised the window is clipped with `SetWindowRgn` to the hit rects under the cursor (all of them while pinned), so the rest of the screen stays what it was and clicks there reach icons, taskbar and other windows. Inside a rect the wallpaper copy sits exactly over the real wallpaper, so the cut-out is invisible; only icons inside that rect are covered for the moment.
- Channel `agent_office/desktop` (`lib/desktop/desktop_layer.dart`): `enterWallpaperMode`, `bringToFront`, `sendToBack`, `setHitRects`, `screenSize`, `wallpaper`, `peek` (ms: show the reported rects over other windows without focus, lower on the timer), `quit`; the runner calls back `focusLost` when another process took the foreground while a bubble was open, and `hotkey` on Ctrl+Alt+Space (`RegisterHotKey` in `flutter_window.cpp`).

## Using it
- Claude and GPT stand on a floor line 120 px above the bottom; the whiteboard, two desks, the coffee machine and the mailbox stand along it. Drag a station to move it (positions are saved).
- Click an idle character: the prompt bubble. Claude plans and delegates (office task); GPT takes the prompt directly. "Klasör" picks the folder, the chips are the last five. Enter sends, Shift+Enter is a newline, Esc closes. Several tasks can run at once, each in its own folder; a desk that is taken makes the next task wait.
- Click a working character: its status (task, last message, tokens) and "Durdur" (stops the whole office). Click the whiteboard: the tasks grouped by root with the folder. Click the mailbox (flag up = unread): the reports, newest first, with "Kopyala".
- Click a sticky note on the whiteboard: the task bubble (status, context fill %, last events, "Durdur" for that task, "Yönlendir" with a note the session continues with). The TV (where the coffee machine stood) shows Claude's 5-hour and weekly usage bars; click it for the numbers and reset times. A new report pops a notice card over the mailbox for 15 s, raised over other windows; a permission request pops "İzin ver / Reddet" over the character. Ctrl+Alt+Space opens Claude's bubble from anywhere. The prompt bubble has model and effort chips and a "Dosya" button (paths are appended to the prompt).
- Tray icon: "Duraklat"/"Devam" holds new prompts (running work continues), "Ayarlar" opens the settings sheet (claude/codex paths with "Bul", permission mode, fake mode, "Windows ile başlat"), "Çıkış" stops the agents and exits. Esc also quits while the layer has keyboard focus and no bubble is open.
- Settings live in `settings.json` under the app support folder (`%APPDATA%\\<org>\\agent_office_app`, see `OfficeSettings.settingsDirectory`): executables, permission mode, fake mode, station positions, recent folders. Executables and fake mode apply on the next start. Autostart is a `Run` entry under HKCU (launch_at_startup).
- On start the runtime resumes interrupted work (`Supervisor.reconcile`); the board is `<folder>/.agent_office/office.db` per working folder.
- The vendor CLIs are the user's own logged-in `claude` / `codex` (subscription, not an API key: `ANTHROPIC_API_KEY` and friends are scrubbed from the child environment). A bare name is resolved along PATH with the PATHEXT extensions, so npm's `claude.cmd` is found; the extensionless `claude` next to it is the POSIX shim and is skipped (Windows cannot run it).

## Icons
- `tool/make_icon.py` (Pillow) draws Claude's beanie head into `assets/icons/tray_icon.ico` (tray, loaded as a Flutter asset) and `runner/resources/app_icon.ico` (exe/window). Rerun it only when the sprite changes.

## If something is off
- Nothing on the desktop: check the console for "behind the desktop icons" vs "no WorkerW"; on 24H2 the Progman child WorkerW may need `SetWindowPos(workerw, HWND_BOTTOM, …)` under `SHELLDLL_DefView`. To see the window's own output regardless of what is on screen, `PrintWindow(hwnd, dc, PW_RENDERFULLCONTENT)` from a script; black everywhere means the DirectX content is not reaching the window surface.
- Wallpaper looks wrong behind the office: the placement comes from `IDesktopWallpaper::GetPosition`; `wallpaperTiles` in `lib/desktop/wallpaper.dart` mirrors fill/fit/stretch/center/tile/span. "Span" is approximated from the virtual-screen rect.
- Only the primary monitor is covered (`SM_CXSCREEN`/`SM_CYSCREEN`).
- The folder/file pickers (`file_selector_windows`) open owned by the raised layer, so only while a bubble is open.
- Dependencies pinned by the SDK (Flutter 3.41.2): `tray_manager 0.5.3`, `launch_at_startup 0.5.1`, `file_selector 1.1.0`.
